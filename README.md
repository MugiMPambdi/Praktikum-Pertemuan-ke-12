# Praktikum-Pertemuan-ke-12
Program Daftar Nilai Mahasiswa (OOP Python)

Program ini dibuat untuk memenuhi tugas praktikum dengan menerapkan konsep Object-Oriented Programming (OOP) menggunakan Python.
Program digunakan untuk mengelola dan menampilkan data mahasiswa.

📌 Data Mahasiswa Awal
Program sudah otomatis memiliki data berikut:

Nama,	NIM,	Nilai,	Umur,	Alamat

✨ Fitur Program

✔ 1. tampilkan()

Menampilkan seluruh data mahasiswa lengkap: nama, nim, nilai, umur, alamat.

✔ 2. tambah()

Menambahkan data mahasiswa baru.

✔ 3. hapus(nama)

Menghapus data mahasiswa berdasarkan nama.

✔ 4. ubah(nama)

Mengubah data mahasiswa berdasarkan nama.

✨Flowchart

🧩 Cara Kerja Program
1. Program memiliki data awal mahasiswa.
2. User memilih menu:
Tampilkan data
Tambah data
Ubah data
Hapus data
keluar
4. Program menjalankan fungsi sesuai pilihan menu.
5. Program berhenti setelah user memilih menu keluar.
